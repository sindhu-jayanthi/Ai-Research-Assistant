AI Research Assistant

An AI-powered research application that automates web research using FastAPI, SerpAPI, and Google Gemini.

Features

Accepts research topics through a FastAPI endpoint.

Retrieves Google search results using SerpAPI.

Supports exact phrase searching to improve search relevance.

Extracts search titles, URLs, and snippets.

Uses Google Gemini to analyse search results.

Generates concise summaries and key findings.

Provides source links for further research.

Uses asynchronous API calls for efficient execution.

Project Objective

To simplify research by combining web search capabilities with AI-powered analysis, helping users gather information and understand a topic more efficiently.
